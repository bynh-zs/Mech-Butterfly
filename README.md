# 仿生蝴蝶（Mech-Butterfly）零基础复刻实录

从零开始复刻开源扑翼仿生蝴蝶（ESP32-C3）的全过程记录：买料 → 烧固件 → 读懂原理图 → 接线 → 焊接 → 调试 → 3D 打印 → 装配 → 首飞。

本仓库只放**我自己产出的东西**：整理的手册、踩坑记录、接线对照表、原理图逐模块讲解、小工具脚本。
**原作者的固件、原理图、3D 打印件、遥控 APP 均未收录**（无明确开源许可、体积大、且属于作者作品），获取方式见 [作者原始资料](#作者原始资料)。

## 项目背景

- 开源项目作者：抖音「康康的小目标」，项目名 `Mech-Butterfly`
- 主控：ESP32-C3-MINI-1 模组（注意：低清截图常被误读成 S3，实际是 C3）
- 飞控板 IS NOT 拿来主义：作者只给原理图，PCB 要自己画
- 我的方案：**成品 ESP32-C3 开发板 + Mini360 降压模块 + 洞洞板**（试验版），不是作者那种成套定制 PCB

## 几个关键结论（先说坑，省得你重走）

1. **合体固件的模块是冻结的**：作者给的 BLE 版本 `firmware.bin` 里 `Kang_BLE.py` 已烧进内部文件系统且优先于用户文件，想改参数必须改走「官方纯净固件 + 自己上传源码」。
2. **原理图脚号 ≠ 开发板脚号**：原理图上 12、13、18 是模组封装的机械脚号，板上丝印 0、1、2 是 GPIO 号。对应关系靠**网络名同名相连**，不靠脚号对脚号。
3. **电池采样脚有出入**：原理图把 `ADC_BAT` 标在 IO0，但飞控代码 `Battery()` 默认 `pin=1`。以代码为准 → 接排针 `1`。
4. **`.SchDocPreview` 不能拿去改 PCB**：那只是立创 EDA 的预览缓存，不是可编辑工程。
5. **新版 Thonny 的固件对话框没有本地 bin 入口**：只能走终端 esptool 烧本地文件。
