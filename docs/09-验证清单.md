# 验证清单

把散在各文档里的检查项集中成一份，动手前照着勾。任何一项没过就不要通电。

## 一、接线前（硬件自检）

### 电源路径

- [ ] 电池正负极方向已核对（正接正、负接负）
- [ ] Mini360 空载输出实测为 5V（用电表量 OUT+ 对 OUT−）
- [ ] 电池没有直接接到 5V / 3V3 / 任何 GPIO
- [ ] 开发板 5V 排针接的是 Mini360 输出，不是电池原始电压
- [ ] 所有 GND 已汇到同一地网络（板子、舵机、Mini360、分压下臂）

### 电池采样支路（如果接了）

- [ ] 300k 电阻在电池侧，100k 电阻在地侧（**接反中点会超 3.3V**）
- [ ] 中点接的是排针 `1`（GPIO1），不是排针 `0`
- [ ] 电阻精度 1%
- [ ] 中点对地电压实测：7.4V 电池应约 1.85V，8.4V 应约 2.10V

### 舵机

- [ ] 信号线接排针 `4`（左）/ `5`（右），不是电源针
- [ ] 舵机额定电压能接受 5V
- [ ] 舵机线序核对过（作者定义：脚1 信号、脚2 电源、脚3 地）
- [ ] 两只舵机同型号（打印件配套）

### 排针连通性（第三方板必做）

- [ ] 用万用表通断档确认：排针 `4` ↔ 模组 IO4 脚连通
- [ ] 排针 `5` ↔ 模组 IO5 脚连通
- [ ] 排针 `1` ↔ 模组 IO1 脚连通
- [ ] 排针 `5V` 确实是板内 5V 输入，不是其他电压

## 二、首次上电

- [ ] 先只插 USB（不接电池），确认电脑能识别串口
- [ ] Thonny 能连上，Shell 里 `import sys; print(sys.implementation)` 正常回显
- [ ] 板载 LED 有反应（不闪就检查 IO8 是否 RGB 灯）
- [ ] 再接 Mini360 的 5V 到板子，测板子 3V3 排针对地是否 3.3V
- [ ] 最后接电池，接之前再核对一次正负极

## 三、功能验证

### 舵机

- [ ] 单独跑一个最小脚本，让舵机扫 0°→180°→0°
- [ ] 左右舵机分别确认，动作方向正确、没有抖动异常
- [ ] 两个舵机同时动时，板子不复位、不重启

```python
from machine import Pin, PWM
import time

pwm = PWM(Pin(4), freq=50)
while True:
    for us in range(500, 2500, 50):
        pwm.duty_u16(int(us / 20000 * 65535))
        time.sleep_ms(20)
    for us in range(2500, 500, -50):
        pwm.duty_u16(int(us / 20000 * 65535))
        time.sleep_ms(20)
```

### 电池采样

- [ ] 串口打印的电压与万用表实测电池电压误差在合理范围（±0.2V 内）
- [ ] 拔掉电池只插 USB 时读数应接近 0（没有采样源）

```python
from machine import ADC, Pin
adc = ADC(Pin(1))
adc.atten(ADC.ATTN_11DB)
raw = adc.read()
uv = adc.read_uv()
print("raw:", raw, "中点电压:", uv / 1e6, "V", "电池:", uv / 1e6 * 4, "V")
```
