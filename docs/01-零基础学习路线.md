# 零基础学习路线

按"这个项目实际要用到"的顺序排，不是按课程完整度排。每门课后面写了「为什么看」「看哪些」。

## 阶段一 · 烧录固件与跑通代码

### 创乐博 ESP32 MicroPython 零基础（50 集）

- 链接：https://www.bilibili.com/video/BV1F1421f7xT/
- 为什么看：这是整个项目的底座。要从这里学会 Thonny 连接开发板、跑第一个脚本、传文件到板子。
- 重点：前 10 集环境搭建；后面讲 GPIO/PWM/ADC 的集数，正好对应舵机和电池采样。
- 用法：不需要全看完，遇到具体功能（PWM 控舵机、ADC 读电压）再回头定位对应集数。

## 阶段二 · 读懂原理图

### 洋桃电子《极速入门数模电路》（26 集）

- 链接：https://www.bilibili.com/video/av1154530590/
- 为什么看：飞控原理图里有电阻分压、电容滤波、PMOS 开关、肖特基二极管、LDO 稳压，这些全在这门课里。
- **必看 7 集**：`01 / 02 / 03 / 04 / 09 / 15 / 17`
  - 01–04：基础元件、电压电流、电阻串并联 → 看懂 300k/100k 分压
  - 09：二极管 → 看懂 D1 防倒灌、肖特基压降
  - 15：三极管/MOS 管 → 看懂 U1 PMOS 电源切换
  - 17：稳压电路 → 看懂 U9 AMS1117
- 其余集数（运放、振荡器之类）本项目用不上，可以先跳过。

### 嘉立创 EDA 原理图绘制教程

- 链接：https://www.bilibili.com/video/BV1hv14BVEyz/
- 为什么看：作者的 `.SchDocPreview` 只是预览缓存，想真正改电路、画 PCB 得在立创 EDA 里重建。这门课教的就是这个。
- 注意：本阶段只需要"看得懂、画得出"，不用急着打样。

## 阶段三 · 焊接

### 你的第一个电路：从面包板到焊接

- 链接：https://www.bilibili.com/video/BV1TYd8BBEbZ/
- 讲从面包板过渡到焊接到洞洞板，适合完全没动过烙铁的人。

### 零基础学会焊板子

- 链接：https://www.bilibili.com/video/BV1wr421W7Dk/
- 讲烙铁温度、焊锡量、虚焊识别，实操细节比第一门细。

### 洞洞板之焊锡走线焊接

- 链接：https://www.bilibili.com/video/BV1264y1a7fh/
- 本项目试验版就是洞洞板搭的，这门课直接对口：怎么在洞洞板上走线、飞线、避免相邻焊盘短路。

## 阶段四 · 调试工具

### 万用表使用

- 链接：https://www.bilibili.com/video/BV17Bb56yEYG/
- 必须会的三件事：量电压（确认 5V/3.3V 对不对）、通断档（确认排针是否真通到模组脚）、量电阻（确认分压电阻值）。
- **通断档是本项目最重要的技能**：第三方开发板排针顺序和官方板不一定一致，最终以实测为准。

## 阶段五 · 项目专项

### ESP32 驱动舵机

- 链接：https://www.bilibili.com/video/BV1F1Vc6BETy/
- 对应飞控的 PWM0/PWM1。重点理解 50Hz、500–2500µs 脉宽与角度的关系。

### ESP-NOW 通信

- 链接：https://www.bilibili.com/video/av834521387/
- 本项目飞控与遥控器之间用的就是 ESP-NOW（另一版固件用 BLE）。要理解 MAC 地址配对、点对点收发。

## 建议的观看顺序

```
创乐博（环境+GPIO/PWM/ADC）
   → 洋桃 01-04（元件基础）
   → 洋桃 09 / 15 / 17（二极管、MOS、稳压）
   → 万用表
   → 焊接三门
   → ESP32 舵机 + ESP-NOW
   → 嘉立创 EDA（等要画 PCB 时再看）
```

前面几个阶段可以并行，但**焊接一定要在动手接线之前看完**，万用表通断档一定要在接电源之前学会。
