# 飞控原理图逐模块讲解

按作者飞控原理图 PDF 的模块顺序，一张一张讲。每张的结构一样：

> 整图是干什么的 → 元件逐个 → 引脚/工作原理 → 对应到我的开发板 → 哪些要自己接、哪些不用接及原因

我把八张图都讲完了。源文件 `1，电路\飞控\蝴蝶飞控原理图.pdf` 属作者作品，本仓库不收录；高清渲染图见 `assets/fw_schematic_3x.png`。

## 第 1 张 · 主控最小系统（U5 = ESP32-C3-MINI-1）

### 整图是干什么的

让模组能上电启动、能进下载模式、能把控制信号输出到外部。这是整块飞控板的"大脑"。

### 五个组成部分

| 部分 | 元件 | 作用 |
|---|---|---|
| 供电与地 | 模组 3V3 脚、多个 GND 脚 | 给模组供电，建立零电位 |
| 复位电路 | R15（0603，10K）、C7（104=0.1µF）、S3 | EN 脚上拉到 3.3V 才能正常跑；C7 滤波防抖；S3 按下拉低 EN 触发复位 |
| BOOT 下载电路 | R17（0603，10K）、S4 | IO9 上拉；按下 S4 把 IO9 拉低，配合复位进入下载模式 |
| 串口 / USB | 31 TXD0、30 RXD0、27 IO19、26 IO18、R4/R5（0Ω） | 串口用于烧录和打印；IO19/IO18 接 USB D+/D-，0Ω 电阻是差分线预留 |
| 对外功能脚 | IO2、IO3、IO4、IO5、IO6、IO7、IO8、IO9、IO10、IO0、IO1 | 引出去给舵机、采样、LED 用 |

### 关键引脚（网络名 → 用途）

| 模组脚位（机械脚号） | 网络名 | 用途 |
|---|---|---|
| 3 | 3V3 | 模组主供电 |
| 8 | EN/RST | 复位输入，低电平复位 |
| 31 / 30 | TXD0 / RXD0 | 串口发送/接收 |
| 27 / 26 | IO19 / IO18 | USB D+ / D-（经 R4/R5 0Ω） |
| 12 | IO0 → ADC_BAT | 原理图标为电池采样（**与代码不符，见踩坑 #6**） |
| 13 | IO1 | 通用 IO（代码实际用这个做电池采样） |
| 18 / 19 | IO4 → PWM0 / IO5 → PWM1 | 左右舵机 PWM 信号 |
| 22 | IO8 → LED | 指示灯 |
| 23 | IO9 → IO9/BOOT | 下载模式控制 |
| 4、5、9、10、25、28、29、32–35、15、17、24 | NC | 悬空不用 |

> 顶部 36–49 全为 GND，底部 52、左侧 53/1/2/11、右侧 50/51 也是 GND。

### 对应到我的开发板

**整张图基本被成品开发板板载实现了**：模组焊死在板上、R15/C7/S3、R17/S4、USB 座、0Ω 电阻全都在板内做好了。

我需要做的只有一件事：**记住哪些丝印对应哪个网络名**（见 `05-GPIO对照表.md`）。

### 要自己接 / 不用接

| 内容 | 要不要接 | 原因 |
|---|---|---|
| 模组、上拉电阻、滤波电容 | 不用 | 板载已有 |
| 复位按键、BOOT 按键 | 不用 | 板载白色按键已实现 |
| 排针上的 EN | 一般不用 | 板内已上拉，悬空即可；要外接复位键才引线 |
| 排针上的 3V3 / 5V / GND | 按供电方案接 | 见 `06-接线方案.md` |
| NC 脚 | 不接 | 模组内部未连接，引出去也没用 |

## 第 2 张 · LED 指示灯支路

### 整图是干什么的

用一个 GPIO 控制一颗 LED 的亮灭，做状态指示。

### 元件

| 标号 | 元件 | 作用 |
|---|---|---|
| R2 | 0603 限流电阻（图上未标阻值，常见 220Ω–1K） | 把电流压到几 mA，防烧 LED |
| DS1 | 发光二极管 | 被点亮的指示灯 |

### 工作原理：共阳接法

```
3.3V → R2(限流) → DS1 阳极 → 阴极 → GPIO8
```

- GPIO8 **输出低电平** → 有压差 → 有电流 → **灯亮**
- GPIO8 **输出高电平** → 两端都是 3.3V → 无压差 → **灯灭**

注意：和常见的「输出高电平点亮」相反，别写反。

**为什么必须有 R2**：LED 导通后自身压降基本固定（约 1.8–2V），不串电阻的话 3.3V 几乎直接压在二极管上，电流失控会瞬间烧灯。

### 对应到我的开发板

| 原理图 | 开发板 | 状态 |
|---|---|---|
| 3.3V | 板内 3.3V 轨 | 板内连通 |
| R2 | IO8 旁那颗贴片电阻 | 出厂已焊 |
| DS1 | IO8 丝印旁的板载灯 | 出厂已焊 |

### 要自己接 / 不用接

- **不用接**：R2、DS1、3.3V、GND 全在板内。
- **可能要引**：排针 `8`，但如果要外接 LED，**必须自己串限流电阻**，不能把 LED 直接跨在 3.3V 和 IO8 之间。
- **注意**：我板子上 IO8 挂的可能是 RGB 彩灯（单线时序），不是普通单色灯，控制方式不同，见踩坑 #8。

## 第 3 张 · 电池电压采样分压电路

### 整图是干什么的

把电池电压按比例缩小，让 ESP32 的 ADC 能读，从而算电量、做低压报警。

### 元件

| 标号 | 元件 | 作用 |
|---|---|---|
| R20 | 300k | 上臂分压电阻（接电池正极） |
| R21 | 100k | 下臂分压电阻（接 GND） |
| 中点 | — | 分压输出，引出 `ADC_BAT` |

### 工作原理

```
V中点 = Vbat × R21 / (R20 + R21)
      = Vbat × 100k / 400k
      = Vbat / 4
```

| 电池状态 | 电池电压 | 中点电压 | ADC 读数（0–4095 对应 0–3.3V） |
|---|---|---|---|
| 满电 | 8.4V | 2.10V | ≈ 2606 |
| 标称 | 7.4V | 1.85V | ≈ 2296 |
| 低压 | 6.0V | 1.50V | ≈ 1861 |

代码里读到中点电压后 **×4** 还原电池电压（`Kang_Battery.py` 里 `sample_volt = normalized_data*4`，和 1/4 分压比吻合）。

**为什么用 300k/100k 这么大**：分压支路一直接在电池上，电阻越大漏电流越小（满电约 21µA），省电。

**为什么必须分压**：ADC 量程只有 0–3.3V，8.4V 直接进去会烧脚。

### 对应到我的开发板

**板载完全没有这两个电阻**，需要自己在洞洞板上搭。

| 原理图 | 我的板子 |
|---|---|
| R20 300k | 没有，自备（建议 1% 精度） |
| R21 100k | 没有，自备（建议 1% 精度） |
| ADC_BAT 中点 | 接排针 `1`（GPIO1，以代码为准） |
| GND | 板上任一 GND（共地） |

### 要自己接 / 不用接

必须自己接四段线：电池正 → 300k → 中点；中点 → 100k → GND；中点 → 排针 1；电池 GND ↔ 板 GND。

**先试飞可以先不接**：排针 1 悬空，只是读不到电量，飞行动作不受影响。

## 第 4 张 · 电池输入接插件（J1 / J2）

### 整图是干什么的

电池的物理入口。J1 进正极并命名 `Vbat_2S`，J2 进负极并命名 `GND`。

### 元件

| 标号 | 元件 | 说明 |
|---|---|---|
| J1 | Header 2（2 针排针/座） | 第 1 脚接电池正极 → `Vbat_2S` |
| J2 | Header 2 | 第 1 脚接电池负极 → `GND` |

J1/J2 **不调压、不滤波**，只是两个接线端点；另一脚图上未连线（以完整原理图为准）。

### 这一张为什么和上一张"重复"

不是重复。原理图靠同名网络连通的：

```
电池正极 → J1 → Vbat_2S ──┬─→ 分压采样
                          └─→ 降压模块
电池负极 → J2 → GND ──────── 全板共地
```

第 4 张是**源头**，第 3 张是**取样支路**。同一个网络名在两处出现，电气上就是同一根线。

### 对应到我的开发板

**没有电池专用插座**。我的等效做法：

| 作者 | 我的方案 |
|---|---|
| J1 电池正极入口 | Mini360 OUT+ → 板子 5V 排针 |
| J2 电池负极入口 | Mini360 OUT- → 板子 GND 排针 |

### 要自己接 / 不用接

要接：电池正 → Mini360 IN+，Mini360 OUT+ → 板子 5V；电池负 → Mini360 IN-，OUT- → 板子 GND。

**禁止**：`Vbat_2S` 是 7.4–8.4V，绝不能直接进 3V3 排针或任何 GPIO。

## 第 5 张 · USB Type-C 接口（typeC1，typec-16p）

### 整图是干什么的

把 USB 的电源线和数据线分开引出：VBUS/GND 进电源轨，D+/D- 连模组 USB 脚，外壳接机壳地。

### 引脚

| 脚号 | 网络名 | 作用 |
|---|---|---|
| 1、12 | GND | USB 地 |
| 2、11 | VBUS | USB 5V 输入 |
| 6、8 | DP1 / DP2 | D+ 数据正（正反两面各一组，并联） |
| 7、5 | DN1 / DN2 | D- 数据负（并联） |
| 4 | CC1 | 配置脚，图上打叉悬空 |
| 10 | CC2 | 配置脚，悬空 |
| 9 | SBU1 | 辅助信号，悬空 |
| 3 | SBUS2 | 辅助信号，悬空 |
| 13、14 | SHELL | 金属外壳，接机壳地 |

### 工作原理：两条独立通道

**供电：**
```
USB VBUS → 脚 2/11 → 板上 5V 轨 → LDO → 3.3V
USB GND  → 脚 1/12 → 板上 GND
```

**数据（差分）：**
```
USB D+ → DP1/DP2 并联 → usb+ → R4(0Ω) → 模组 IO19
USB D- → DN1/DN2 并联 → usb- → R5(0Ω) → 模组 IO18
```

Type-C 正反可插，所以 D+/D- 各有两组触点，板上并联成一对。

### 对应到我的开发板

**板载 micro USB 座代替**，USB 座、5V/GND、D+/D-、壳地全已焊好。

### 要自己接 / 不用接

**全不用接**，插 USB 线即可。CC1/CC2、SBU1/SBU2 图上已悬空，不要引线。

**待核**：CC 脚悬空严格来说可能影响主机枚举，但作者板上大概率还有 USB 转串口芯片配合；我板子插电脑能出串口就是正常的。

**接口类型差异**：作者是 Type-C，我的是 micro USB。电气上认的都是 5V/GND/D+/D- 四根线，CC/SBU 本来就没用，所以**在连接电路上没有本质影响**。唯一要注意：买线必须买**数据线**，只充电的线 D+/D- 是空的。

## 第 6 张 · 舵机接口（P1 / P2）

### 整图是干什么的

把两路 PWM 信号、舵机电源、地引到两个 3 针座上，供左右舵机插接。这是蝴蝶的执行机构。

### 引脚

**P2（左舵机）**

| 脚 | 网络名 | 作用 |
|---|---|---|
| 1 | PWM0 | 信号，来自 IO4 |
| 2 | Vbat_2S | 舵机电源正（图上直连电池） |
| 3 | GND | 舵机地 |

**P1（右舵机）**

| 脚 | 网络名 | 作用 |
|---|---|---|
| 1 | PWM1 | 信号，来自 IO5 |
| 2 | Vbat_2S | 舵机电源正 |
| 3 | GND | 舵机地 |

### 工作原理

**信号**：50Hz PWM，脉宽 500–2500µs 对应 0–180°（对应代码 `Kang_Sevor.py` 的 `freq=50, min_us=500, max_us=2500`）。靠脉宽定角度，不是简单高低电平。

**动力**：电池正极 → 脚 2 → 舵机电机；电池负 → 脚 3 → 舵机地。

**为什么必须共地**：舵机判断信号高低以自己的地为 0V 参考，不共地会乱抖或不动作。

### 对应到我的开发板

| 原理图 | 我的板子 |
|---|---|
| PWM0 | 排针 `4`（代码 `Servo(pwm_pin=4)`） |
| PWM1 | 排针 `5`（代码 `Servo(pwm_pin=5)`） |
| Vbat_2S | 舵机供电（我的方案走 Mini360 的 5V） |
| GND | 板上 GND |

### 要自己接 / 不用接

两个舵机各三根线都要自己接：

| 舵机 | 信号 | 电源 | 地 |
|---|---|---|---|
| 左 | → 排针 4 | → 5V 汇流 | → GND |
| 右 | → 排针 5 | → 5V 汇流 | → GND |

**插线前核对针序**：作者是「脚1信号、脚2电源、脚3地」。舵机线色常见为橙/黄=信号、红=电源、棕/黑=地，但各家有差异，**千万别把电源插进信号脚**，会烧 IO。

**耐压提醒**：图上脚 2 直接取 2S 电池（7.4–8.4V）。微型舵机常见额定 4.8–6V，**不一定扛得住 8.4V**。接线前必须查你选的舵机规格，走 5V 汇流更稳妥。

## 第 7 张 · 3.3V 线性稳压（U9 = AMS1117-3V3）

### 整图是干什么的

把上游 5V（VCC）稳压成 3.3V，给模组和所有 3.3V 器件供电。这是前面几张图里 `3.3V` 轨的来源之一。

### 元件

| 标号 | 元件 | 作用 |
|---|---|---|
| U9 | AMS1117-3V3，SOT-223 | 固定 3.3V 输出的 LDO |
| U9 脚 3 | IN | 输入，接 `VCC`（5V） |
| U9 脚 1 | GND | 地 |
| U9 脚 2 | OUT | 输出 3.3V |
| U9 脚 4 | TAB | 散热焊盘，接 GND 铺铜 |
| C1 | 100µF 极性电容 | 输出滤波、负载突变时储能 |

### 工作原理

```
VCC(5V) → U9 IN → OUT → 3.3V → 模组 / LED / 上拉电阻
                 GND
```

LDO 靠内部调整管"吃掉"压差（5V−3.3V = 1.7V，AMS1117 低压差约 1.1V，够用），特点是**纹波小、电路简单**，代价是压差变热量、效率低于 DCDC。本项目主控功耗小，发热可接受。

C1 作用：把电压波动压平；舵机/模组瞬时电流变化时先顶一下，避免 3.3V 被拉跌导致模组重启。

### 对应到我的开发板

**板载同类型 LDO 已经做了这一整路**，U9、C1、输入输出全在板内。排针 `3V3` 就是这一路的对外引出点。

### 要自己接 / 不用接

**全不用接**。插 USB 或接 5V，板上 LDO 自动出 3.3V。

**自搭时注意**（如果以后画板）：
- C1 是极性电容，**+ 接 3.3V、− 接 GND**，反接有爆裂风险；
- 输入侧按手册还应就近放一颗约 10µF 电容，这张图只画了输出 100µF，自搭时别漏；
- `VCC` 究竟是不是 5V，见下一张。

## 第 8 张 · 双路电源切换 + 防反接

### 整图是干什么的

两个电源（USB 5V 和电池）经隔离器件汇到同一条 `VCC` 轨，送给第 7 张的 LDO。同时兼做防倒灌、防反接、输入滤波。这是整板的电源汇流排。

### 元件

| 标号 | 元件 | 作用 |
|---|---|---|
| U1 | P 沟道 MOS（P-MOS） | 电池路高边开关，兼防反接 |
| D1 | 肖特基二极管 | 5V 路单向导通，阻止电池倒灌进 USB |
| R1 | 10K 下拉 | USB 拔掉时把该节点拉到地，保证 MOS 栅极电平确定 |
| C2 | 104 = 0.1µF | 高频滤波 |
| C3 | 10µF | 储能滤波 |
| VCC | 输出轨 | 送第 7 张 LDO 输入 |

### 三种工作状态

**① 只插 USB**
```
USB 5V → D1 正向导通 → VCC → LDO → 3.3V
MOS 路：无电池电压，截止
```
肖特基压降约 0.3–0.5V，所以 VCC 略低于 5V。

**② 只接电池**
```
电池 7.4V → U1(MOS) 导通 → VCC → LDO → 3.3V
D1：反偏截止，电池不会倒灌 USB
```
R1 把节点拉地，MOS 栅极低电平、源极高电平 → 导通。

**③ 两路同时**
按器件阈值自然汇合。**哪一路优先**取决于 MOS 的栅源阈值和两路压差，我不断言，要实测 VCC 电压确认。

**防反接**：MOS 串在电池正极，接反时源漏电位反转，沟道和体二极管都不形成正向大电流回路。但这只是兜底，接线仍要先核对正负极。

### 对应到我的开发板

**成品开发板基本没有这套电路**：

| 原理图 | 我的板子 |
|---|---|
| U1 MOS（电池开关/防反接） | 没有 |
| D1 防倒灌 | 一般没有 |
| R1 下拉 | 没有 |
| C2/C3 | 板载 LDO 周边有等效电容，但不是这套组合 |
| 双路自动切换 | 没有，靠手动插拔 |
| VCC 轨 | 对应 5V 排针之后的内部输入轨 |

### 为什么要简化掉

- **自动切换用不上**：调试插 USB、飞行接电池，手动插拔就完成了切换；
- **成品板本身没有电池直供通道**：我的电池是经 Mini360 降到 5V 后从排针进的，不存在板内 OR-ing；
- **原型阶段优先少元件**：洞洞板上节点越少出错越少。

### 简化的代价（要心里有数）

| 原功能 | 简化后 | 风险 |
|---|---|---|
| USB/电池自动切换 | 手动插拔 | 两路别同时乱接 |
| 防倒灌 D1 | 省略 | 注意别让电池电反向灌进 USB 口 |
| 防反接 MOS | 省略 | **接反没有保护，可能烧板**，接线前必核对 |
| C2/C3 滤波 | Mini360 输出电容 + 板载电容部分承担 | 舵机大电流动作时留意是否重启 |

**什么时候要加回来**：准备把飞控做成自己的 PCB（打样贴片）、或长期装机飞行需要可靠电源保护时，第 7、8 张都要重新画回板子上。

## 八张图串起来的整板供电链

```
电池 2S ── J1/J2 ──┬─ 分压 R20/R21 → ADC(IO1)  【测电量】
                   └─ U1(PMOS) ──┐
USB 5V ── Type-C ── D1 ────────┴─→ VCC ──→ U9(AMS1117) ──→ 3.3V ──→ 模组/LED/上拉
                                  C2/C3 滤波
舵机：P1/P2 ← IO4/IO5(PWM) + 舵机电源 + GND
```

我的 Mini360 方案对应关系：

```
电池 7.4V → Mini360 → 5V(=作者的VCC) → 板载LDO → 3.3V
                    └→ 舵机电源
电池 7.4V ──┬─ 300k → 中点 → 100k → GND → 中点到排针1
```

Mini360 只替代了「电池高压 → 5V」这一级 DCDC；LDO、采样、舵机接口都不替代。
