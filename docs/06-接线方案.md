# 接线方案（成品开发板 + Mini360 试验版）

这是我的实际方案：不做作者那种定制 PCB，用「第三方 ESP32-C3 开发板 + Mini360 降压模块 + 洞洞板」先把功能跑起来。

## 一、整体拓扑

```
电池 2S (7.4–8.4V)
  │
  ├─[正极]─┬─ Mini360 IN+ ──> OUT+ (5V) ──┬─ 开发板 5V 排针
  │        │                              ├─ 左舵机 电源正
  │        │                              └─ 右舵机 电源正
  │        │
  │        └─ 300k(R20) ──┬─ 中点 ── 开发板排针 1 (GPIO1)
  │                       │
  │                    100k(R21)
  │                       │
  └─[负极]─┬──────────────┴─ GND 汇流 ──┬─ 开发板 GND
           │                            ├─ 左舵机 GND
           ├─ Mini360 IN− / OUT−         └─ 右舵机 GND
           │
           └────────────────────────────── (所有地共一处)
```

## 二、正极怎么走（供电主链路）

| 顺序 | 节点 | 说明 |
|---|---|---|
| 1 | 电池正极 | 原始 2S 高压侧，**只进 Mini360 和分压支路** |
| 2 | （可选）电源开关 | 串在正极总线上，两条支路之前；断开即全断电 |
| 3 | Mini360 IN+ | 降压模块输入 |
| 4 | Mini360 OUT+ | 降到 5V，**上电前先空载用电表量，确认是 5V** |
| 5A | 开发板 `5V` 排针 | 给主控板供电，板内自己降到 3.3V |
| 5B | 两个舵机电源正 | 前提是舵机支持 5V 供电 |

**禁止**：电池正极直接进 `5V`、`3V3` 或任何 GPIO。

## 三、负极怎么走（共地）

一条地网络，所有设备都汇到它：

```
电池负极 → Mini360 IN− / OUT−
        → 开发板 GND（任一 GND 排针）
        → 左舵机 GND
        → 右舵机 GND
        → 分压下臂 100k 下端
```

**地必须全部连通**，缺任何一个：
- 舵机会乱抖或不动作（信号没有参考电位）；
- ADC 读数乱跳（浮动电位）；
- 整个电路不工作。

## 四、电池采样支路（要电量功能才接）

```
电池正极（降压前）→ 300k → 中点 → 100k → GND
                            └→ 开发板排针 1 (GPIO1)
```

要点：
- 采样点取**电池侧**（降压前），不是 5V 侧；
- **300k 在上（电池侧）、100k 在下（地侧）**。接反中点会变成 3/4 电池电压，可能超 3.3V 烧 ADC；
- 分压支路一直并在电池上，耗电 µA 级，不用单独开关；
- **先试飞可以整路不接**，排针 1 悬空，只是没有电量读数。

验算：电池 7.4V → 中点 1.85V → ADC 读数 ≈ 2296 → 代码 ×4 → 7.4V。

## 五、舵机三线

| 舵机 | 信号 | 电源正 | 地 |
|---|---|---|---|
| 左 | → 排针 `4` | → 5V 汇流 | → GND |
| 右 | → 排针 `5` | → 5V 汇流 | → GND |

**插线前核对针序**：作者定义是「脚1 信号、脚2 电源、脚3 地」。舵机线常见橙/黄=信号、红=电源、棕/黑=地，但各家有差异。**电源插进信号脚会直接烧 IO。**

**耐压**：我方案里舵机走 5V 汇流（不是作者那种电池直供 7.4–8.4V）。买舵机时确认额定电压覆盖 5V。

## 六、建议的上电顺序

1. **先不接电池**，USB 插电脑给开发板供电，确认能连、代码能跑；
2. Mini360 空载，用电表确认输出 5V；
3. 接 Mini360 OUT 到开发板 5V + GND；
4. 接舵机电源与信号线；
5. 最后接电池，**接之前再核一次正负极**。

## 七、和作者原方案的差异

| 项目 | 作者方案 | 我的方案 |
|---|---|---|
| 主控板 | 自制 PCB（贴片集成，约 3×4cm） | 成品开发板 + 洞洞板（体积大很多） |
| 电池到 5V | 板上 DCDC 芯片电路 | Mini360 成品模块外挂 |
| 5V 到 3.3V | 板上 U9 AMS1117 | 板载 LDO（已集成） |
| 双路切换/防反接 | 有（第 8 张） | 无，手动插拔 + 自己核对正负极 |
| 电池采样 | 板上 R20/R21 | 洞洞板自搭 |
| 舵机接口 | 板上 P1/P2 座 | 杜邦线直连 |

**体积问题的解法**（三种，见后续考虑）：A. 嘉立创 EDA 转 PCB 打样贴片；B. 洞洞板最小化重排；C. 先飞起来再优化尺寸。

## 八、安全清单（接电前逐条过）

- [ ] 电池正负极方向核对过
- [ ] Mini360 空载输出确认为 5V
- [ ] 电池没有直接接到 5V/3V3/GPIO
- [ ] 所有 GND 已汇到同一地网络
- [ ] 分压电阻 300k 在上、100k 在下
- [ ] 舵机信号线接的是 4 / 5，不是电源针
- [ ] 舵机额定电压确认能接受 5V
- [ ] USB 和电池没有同时乱接
